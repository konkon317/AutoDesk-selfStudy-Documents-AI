① Mocap修正 vs ゼロ制作 — 何が同じで何が違うか

🎥 Mocap修正

  • 入力データMocapデータあり（骨格キーフレームの塊）
  • Control RigReach < 100%でMocapと合成（上書き強度を調整）
  • 作業量比較的少ない。問題箇所だけ直す
  • 向く場面大量データ処理、人の自然な動き、実写リファレンスあり
  • 強みリアルな重量感・慣性が自動で入っている

✏️ ゼロから制作

  • 入力データなし（白紙から）
  • Control RigReach 100%でControl Rigが完全支配（or FK直打ち）
  • 作業量多い。全フレームを自分で設計する
  • 向く場面完全オリジナル動作、誇張表現、Mocapが撮れない動き
  • 強み意図を100%反映できる。物理法則を無視してよい
🤝 どちらでも変わらない共通構造
Characterize → Control Rig 作成 → エフェクター / FK で意図を指定 → Plot to Skeleton → FBX 書き出し

構造が同じということは、Control Rigの使い方を覚えるとMocap修正にもゼロ制作にも使い回せるということです。使う道具は変わらず、「何を入力するか」と「Reachをどう設定するか」だけが変わります。

③ FK / IK の選び方（ゼロ制作視点）

FK が向く場面

  • 体をひねる・上半身の表現——脊椎・腰のねじれはFK的な積み上げが自然
  • 流れるような腕振り——波打つような動きはFKの方がコントロールしやすい
  • 顔・首の向き——頭のコントロールはFK的な操作が直感的
  • 表情的な上半身——感情を乗せる動きはFKで細かく調整

IK が向く場面

  • 足を床に固定する——フットプラントはIK+Pinningが必須
  • 手で何かを掴む・触れる——物体の位置に手を合わせるのはIKが直感的
  • 重心移動を主体に考える——Hips Effectorで全身の重心を動かす
  • 壁・机への接触——接触位置を固定したままキャラを動かす
💡

実際の制作では混在： 下半身はIK（足を地面に固定）、上半身はFK（腕の振りを細かく制御）という使い分けが一般的です。MBのControl Rigではエフェクターごとに独立してIK/FKを切り替えられます。

MotionBuilderのFCurveエディタはMayaのGraph Editorと同じ役割を持ちます。両方使う場合、どちらかを覚えればもう一方は操作感がほぼ移植できます。

📌

FBX経由で持ってきたアニメーションの確認： MBでMocapデータを開いた直後にFCurveエディタでカーブを見ると、ノイズや異常値（スパイク）が見えることがあります。修正前に一度確認しておくとどこを直すべきかが把握できます。

⑤ ゼロ制作ワークフロー（ステップ解説）

Mocap修正との違いが出るステップを強調しています。

1

キャラクターをCharacterize（Mocap修正と同じ）

CGモデルのスケルトンをMBに認識させる。ゼロ制作でも必要。

Mocap修正と同じ
2

Control Rigを作成（Mocap修正と同じ）

Character Controls → IK/FK Control Rig を作成。

Mocap修正と同じ
3

全エフェクターのReachを100%に設定

Mocap修正では「修正する部位だけ上げる」が、ゼロ制作では全部位を自分でコントロールするため全て100%にする。

ゼロ制作特有
4

フレーム0でT字ポーズ（またはAポーズ）を確認

キャラクターが正しい初期姿勢にあることを確認してからアニメーションを開始する。

ゼロ制作特有
5

主要ポーズをキーで打つ（ポーズtoポーズ）

まず動きの「山」となるポーズだけキーを打つ。例: フレーム1（立ち）→ 30（ジャンプ頂点）→ 60（着地）。FCurveエディタで確認しながら進める。

ゼロ制作特有
6

中間ポーズ・タイミングを調整

FCurveエディタでカーブのタンジェントを整えて緩急をつける。必要に応じて中間フレームにキーを追加。

ゼロ制作特有
7

Plot to Skeleton → FBX書き出し（Mocap修正と同じ）

完成したらPlotしてスケルトンに焼き付け、FBXで書き出す。

Mocap修正と同じ

⑥ Mocapと手付けアニメの組み合わせ

実務でよくある「ベースはMocap、一部を手で上書き」というハイブリッドパターンです。

Reach によるブレンド

修正したいエフェクターのReachだけを100%に上げる。他はMocapのまま。フレームごとにReachにキーを打てば「徐々に手付けアニメに移行」もできる。

  • 例： 足はMocap（Reach 0%）、右手だけ物を掴む動き（Reach 100%）

Animation Layers（加算レイヤー）

既存のアニメーションの上に差分アニメーションを「加算」で重ねる。元データを壊さずに揺れ・ブレ・呼吸などを追加できる。

  • ベースレイヤー：Mocap（修正済み）
  • 追加レイヤー：手付けの揺れ・微調整
🖐

試してみる： 既存のMocapで右手のReachを0%→100%に変えた後、Hand Effectorを動かして「右手で何かを指さす」ポーズを追加してみる。下半身・左腕はMocapのまま残ることを確認する。

⑦ 手付けアニメーション — キーを打つ基本サイクル

MB はMocap処理ソフトですが、Control Rig を使って手付けアニメーションをゼロから作ることもできます。基本サイクルは「フレームを決める → エフェクターを動かす → キーを打つ」の繰り返しです。

→
機能
→
理屈
ポーズを1フレームずつ決めたい
→
エフェクターを動かして K キーでキーを打つ
→

FK で回転を直打ちしたい
→
ボーンを選択して Rotation を変えてキーを打つ

FK モードではボーンの Rotation チャンネルに直接キーが積まれる。親から順に回転が伝播する

基本キーイングサイクル（IK 手付け）

1

Control Rig を Active にして Reach を 100% に設定

全エフェクターの Reach（T・R 両方）を 100% にする。Mocap データがなければ 0% でも同じ結果になるが、意図を明確にするため 100% 推奨。

2

始点フレームへ移動してすべての Control をキー打ち

Transport Controls でフレームを指定。A で全オブジェクト選択 → K（または Character メニュー → Key All）でTポーズを初期キーとして記録する。

3

目的のフレームへ移動 → エフェクターを動かす

動かしたいエフェクターを選択して W（Move）または E（Rotate）で位置・角度を変更する。

4

K キーで選択中のエフェクターにキーを打つ

選択オブジェクトにキーが記録される。全身まとめて打ちたいときは A で全選択してから K。

5

次のキーフレームへ移動して繰り返す

主要ポーズだけ打ってから FCurve エディタでタイミングと緩急を調整する。ポーズ to ポーズの繰り返しがゼロ制作の基本単位。

📌

MBの手付けは「粗打ち → Mayaで仕上げ」が現実的： MB の Dopesheet はキー管理が Maya より不便です。主要ポーズだけ MB で作り、FBX で Maya に渡してから Graph Editor で緩急・タイミングを整えるフローが実務では一般的です。

⑧ 人型以外のアニメーション — Characterize できないオブジェクトの扱い

MB の Control Rig は HumanIK（人型ボーン構造）専用です。4足・乗り物・小道具など人型でないオブジェクトには Characterize が使えず、アプローチが変わります。

対象
→
MBでの扱い方
→

小道具・武器（持ち物）
→

→
Position / Rotation Constraint が MB に組み込まれており、ターゲットボーンを指定するだけで追従できる。Plot で独立したキーに焼き付ける
乗り物・単純なメカ
→
ルートボーンに直接キーを打つ（Raw アニメ）
→
Control Rig を使わない場合、ボーンの Translate / Rotation チャンネルに直接キーが積まれる通常のキーアニメになる
4足歩行・非人型キャラクター
→
人型部分だけ MB で処理 → 残りは Maya へ
→
HumanIK は人型マッピング前提のため4足対応は限定的。Maya のほうが柔軟なリグを組める

3つのアプローチ比較

① 直接ボーン操作（Raw）

Control Rig なしで直接ボーンを選択して Rotate / Translate を変えてキーを打つ。

  • シンプルな乗り物・単純な小道具
  • ループしない単発アニメ
  • 操作が直感的・FCurve で完結

② Constraint（追従）

武器・持ち物など「人体に追従させたいオブジェクト」に Position / Rotation Constraint を設定し、手ボーンを親にする。最後に Plot して独立したアニメに焼き付ける。

  • 武器・持ち物全般
  • 騎乗キャラの体固定
  • MB の Constraint ペインで設定

③ Maya に渡す

人型部分だけ MB で処理して FBX 書き出し。非人型部分は Maya でリグを組んで Graph Editor で仕上げる。

  • 4足歩行キャラクター
  • 複雑なメカ・テール・翼
  • 最終品質が重要な場合
💡

Constraint の Plot を忘れずに： Constraint を使ったオブジェクトは、FBX 書き出し前に必ず Plot（Constraint の結果をキーフレームに焼き付け） してください。Plot なしで書き出すと Maya 側で Constraint が失われ、オブジェクトが元の位置に戻ってしまいます。
