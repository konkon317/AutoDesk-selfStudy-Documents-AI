① Animation Layer — 元データを壊さずに修正を重ねる

既存のアニメーション（Mocapや手付け済みデータ）に元データを破壊せずに修正・追加動作を重ねる仕組みです。レイヤーを off にすればいつでも元の状態に戻せます。このページの③（部分上書き）でも使うので、最初に道具として覚えます。

Animation Layer の追加手順

1

Animation Layer パネルを開く

メニュー Window → Animation Layer Editor。BaseAnimation レイヤーが表示されていれば現在のアニメーションが乗っている。

2

+ ボタンで新規レイヤーを追加する

追加したレイヤーが選択状態になる。以後このレイヤーにキーが記録される。

3

追加レイヤーを選択した状態でキーを打つ

修正したいフレームに移動してポーズを変えて K。BaseAnimation には一切触れない。

4

Layer Weight でブレンド強度を調整する

0%〜100% で追加レイヤーの加算強度を変えられる。フレームごとにキーを打てば「徐々に修正が入る」効果も作れる。

📷 Animation Layer Editor の実画面スクリーンショット（実機セッションで撮影予定）— BaseAnimation ＋ 追加レイヤー1枚、Weight スライダーが見える状態
直接編集 Animation Layer
元データ 変更される（上書き） 保持される（触らない）
取り消し Undo のみ（セッションをまたげない） レイヤーを off または削除するだけ
向く場面 最終的に確定した修正を入れるとき 試行錯誤しながら差分を積むとき、Mocap修正の試し打ち

② Plot — アニメーションを焼き付ける・焼き替える

Plot は「現在のアニメーション状態をキーフレームとして確定させる」操作です。どこに焼き付けるかによって操作と目的が変わります。

Plot to Control Rig の手順（スケルトン → Control Rig）

1

キャラクターが Characterize 済みであることを確認

Character Controls パネルを開き、キャラクター名が表示されていれば OK。FBX インポート後などは再 Characterize が必要な場合がある。

2

Control Rig を作成（まだない場合）

Character Controls パネル上部のメニューから Create > Control Rig。FK / IK のどちらでも可。

3

Edit → Plot Character → "Control Rig" を選択

Character Controls パネルの Edit メニューから実行。フレームレンジの確認ダイアログが出るので範囲を設定して OK。

4

Control Rig のエフェクターにキーが生成される

以後は FCurve エディタや Character Controls でエフェクターのキーを直接編集できる。

📷 Plot Character ダイアログの実画面スクリーンショット（実機セッションで撮影予定）— Edit → Plot Character 実行時のフレームレンジ設定画面
スケルトンに焼き付け済みのアニメーションも同じ手順で OK
FBX で持ってきた「すでにボーンにキーが乗っているアニメーション」も、キャラクターを Characterize さえすれば同じ手順で Control Rig に焼き替えられます。MBはCharacterize済みの骨格に乗っているキーをFKソースとして読むため、データの出所（Mocap・手付け・他ツール書き出し）は問いません。

Plot to Skeleton の手順（逆方向 / FBX書き出し前）

Control Rig 上で編集した結果を スケルトンボーンのキーに確定させます。FBX書き出し前に必要な工程です。

1

Edit → Plot Character → "Character" を選択

Control Rig の状態がスケルトンボーンのキーに変換される。

2

FBX 書き出し

Plot 済みのスケルトンキーが FBX に含まれる。Maya でそのまま再生できる状態になる。

別キャラへの再 Retarget（応用）

手順内容
① ソース・ターゲット両方を Characterize骨格が違ってもどちらも HumanIK マッピングが完了していれば OK
② ターゲット側の Character Controls を開くSource のプルダウンでソースキャラ名を選択
③ Edit → Plot Character → "Character"ターゲット側で実行。ソースの動きがターゲットの骨格比率に変換されて焼き付けられる
Characterize が大前提
Plot 操作は Characterize（HumanIK マッピング）があって初めて成立します。FBX インポート直後は Characterize が解除されている場合があるため、Plot 前に Character Controls パネルでキャラクター名が表示されているかを必ず確認してください。
🚩 ここで一区切り — 道具が揃ったら
  • Animation Layer を1枚追加し、キーを打ち、目のアイコンで on/off して元に戻ることを確認した
  • Plot の3方向（→ Control Rig／→ Character／別キャラへ）の違いを自分の言葉で言える

③ Mocap × 手付けの部分上書き — 3つのアプローチ

実務でよくある「全体の動きはMocapのまま、特定部位・特定区間だけ手付けに置き換える」パターンです。①②で覚えた道具を組み合わせて、目的に応じて3つのアプローチから選びます。

💡

Reach（IK Blend T/R）の復習： どのアプローチでも「エフェクターがどれだけ Mocap を上書きするか」は Reach で制御します。UI 上の実名（IK Blend T/R・IK Pull）との対応表は Control Rig ⑤ を参照。

アプローチ 向く場面 元データへの影響
A: Reach で部位ごとに上書き 特定エフェクター（手・頭など）の動きを置き換えたい Mocapはそのまま残る
B: Animation Layer で差分を加算 試行錯誤しながら修正したい。元に戻しやすくしたい Base Layer は変更なし
C: Plot to CR → 直接編集 特定区間を完全に手付けに置き換えたい。最大の自由度が必要 CR キーを上書き（元Mocapは失われる）

アプローチ A — Reach を使った部位単位の上書き

1

上書きしたい部位の IK Blend T/R を 100% に設定

例：右手だけ上書きしたいなら Right Hand Effector の IK Blend T / IK Blend R を 100% に。他の部位は 0% のままで Mocap が流れ続ける。

2

手付けを入れたいフレームでエフェクターを動かして K

Mocap の動きに重ねて新しいポーズをキーとして記録する。Reach 100% のエフェクターだけが上書きされ、他は Mocap のまま。

3

Reach 自体にキーを打って「移行区間」を作る

上書きが始まるフレームの手前で Reach = 0% にキーを打ち、上書き区間に入るところで Reach = 100% にキーを打つ。これで「Mocap → 手付けへの自然な移行」が作れる。

🖐

試してみる： 既存のMocapで右手のReachを0%→100%に変えた後、Hand Effectorを動かして「右手で何かを指さす」ポーズを追加してみる。下半身・左腕はMocapのまま残ることを確認する。

アプローチ B — Animation Layer で区間を絞って差分を乗せる

1

Animation Layer を追加してその上にキーを打つ

ベースレイヤーの Mocap は一切触れない。新しいレイヤーに修正差分のキーだけ記録する。追加手順はこのページ①のとおり。

2

Layer Weight にキーを打って「有効区間」を限定する

修正を入れたい区間の前後で Weight = 0 → 100 → 0 のようにキーを打つ。区間の外では修正レイヤーが無効になり Mocap だけが再生される。

アプローチ C — Plot to Control Rig → 区間を直接置き換える

1

Mocap を Control Rig に焼き付ける（Plot to CR）

手順はこのページ②のとおり。全フレームの CR キーが得られ、FCurve 上で自由に編集できる状態になる。

2

置き換えたい区間のキーを FCurve エディタで編集・削除

問題区間のキーをドラッグ選択して Delete → 新しいポーズをキーとして打ち直す。前後の区間はそのまま残るので、スプライン補間でつながる。

3

Butterworth フィルターで境目を滑らかにつなぐ

置き換えた区間の前後で急激な変化が出る場合は、その部分を選択して Edit → Filter → Butterworth でスムーズをかける。カーブの細かい振動を落として滑らかにするフィルターで、つなぎ目の「段差ならし」に効く。

「突出した感じ」が出る原因と対処
Mocap データは密なキーが全フレームに入っているため、1フレームだけ変えると前後の古いキーとの間で急激なカーブになります。アプローチ C の場合は「問題区間のキーを削除してから新しいキーを打つ」のが最短の解決策です。削除したくない場合は Butterworth フィルターで区間全体をスムーズに。
Mocap修正の定番フロー：Reach ＋ Animation Layer
修正したい部位の IK Blend T/R（Reach）を 100% に上げて Animation Layer 上でキーを打つと、元のMocapを保持したまま上半身・手先だけを修正できます。確定したら Plot to Skeleton して FBX へ。

④ 人型以外のアニメーション — Characterize できないオブジェクトの扱い

MB の Control Rig は HumanIK（人型ボーン構造）専用です。4足・乗り物・小道具など人型でないオブジェクトには Characterize が使えず、アプローチが変わります。

対象
→
MBでの扱い方
→
なぜそうなるか
小道具・武器（持ち物）
→
Constraint で手ボーンに追従させて Plot
→
Position / Rotation Constraint が MB に組み込まれており、ターゲットボーンを指定するだけで追従できる。Plot で独立したキーに焼き付ける
乗り物・単純なメカ
→
ルートボーンに直接キーを打つ（Raw アニメ）
→
Control Rig を使わない場合、ボーンの Translate / Rotation チャンネルに直接キーが積まれる通常のキーアニメになる
4足歩行・非人型キャラクター
→
人型部分だけ MB で処理 → 残りは Maya へ
→
HumanIK は人型マッピング前提のため4足対応は限定的。Maya のほうが柔軟なリグを組める

3つのアプローチ比較

① 直接ボーン操作（Raw）

Control Rig なしで直接ボーンを選択して Rotate / Translate を変えてキーを打つ。

  • シンプルな乗り物・単純な小道具
  • ループしない単発アニメ
  • 操作が直感的・FCurve で完結

② Constraint（追従）

武器・持ち物など「人体に追従させたいオブジェクト」に Position / Rotation Constraint を設定し、手ボーンを親にする。最後に Plot して独立したアニメに焼き付ける。

  • 武器・持ち物全般
  • 騎乗キャラの体固定
  • MB の Constraint ペインで設定

③ Maya に渡す

人型部分だけ MB で処理して FBX 書き出し。非人型部分は Maya でリグを組んで Graph Editor で仕上げる。

  • 4足歩行キャラクター
  • 複雑なメカ・テール・翼
  • 最終品質が重要な場合
💡

Constraint の Plot を忘れずに： Constraint を使ったオブジェクトは、FBX 書き出し前に必ず Plot（Constraint の結果をキーフレームに焼き付け） してください。Plot なしで書き出すと Maya 側で Constraint が失われ、オブジェクトが元の位置に戻ってしまいます。

🏁 実践編クリアの目安
  • 既存 Mocap の右手だけを Reach で「指さし」に置き換えられた（アプローチ A）
  • Animation Layer で揺れ・微修正を足し、Weight キーで有効区間を絞れた（アプローチ B）
  • Plot to CR → 区間編集 → Plot to Skeleton → FBX の往復を一度自分の手で通せた（アプローチ C）
