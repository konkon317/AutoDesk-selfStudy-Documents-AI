📅 フェーズ 1 — MotionBuilder 深化（MB × 7）

MotionBuilder
UI確認 → Control Rig習得 → Mocap修正実践
既知のワークフローを言語化しながら Control Rig を体に覚えさせる
S1
MB

UI再確認 & 既知ワークフローの言語化

🎯 ゴール：Characterize → Retarget → Bake の流れを自分の手で通しで実行できる
  • ビューポート操作・Asset Browser を確認（30分）
  • テイクシステムの動作確認
  • MocapデータをCharacterizeしてCGモデルにリターゲット → Bakeまで1本通す
  • FBXで書き出して確認
4〜5h
S2
MB

Control Rig の作成とエフェクター把握

🎯 ゴール：Control Rigを自分で作り、各エフェクターを選んで動かせる
  • Character Controls ウィンドウを開く
  • IK Control Rig を作成する
  • 全エフェクター（手・足・腰・頭）を一つずつ選択して動かしてみる
  • Reach = 100% にして動きの追従を確認
  • Reach = 0% にして無効になることを確認
4〜5h
S3
MB

IK / FK の感覚をつかむ

🎯 ゴール：IKとFKの操作の違いを体感として理解できる
  • FK モードで各ジョイントを個別に回転させてみる
  • IK モードで手・足のエフェクターを移動して体の追従を確認
  • Hand Effector を動かして腕全体が追従することを確認
  • Hips Effector を上下させて体全体の重心変化を体感
4〜5h
S4
MB

ピン留め（Pinning）でフットプラントを直す

🎯 ゴール：足のスライドをピン留めで修正できる
  • 歩行Mocapデータを用意して足スライドを確認
  • 着地フレームに Foot Effector の Translation Pin を打つ
  • 離地フレームでピンをオフにする
  • 修正前後を比較して効果を確認
  • 複数ステップ分繰り返して精度を上げる
5〜6h
S5
MB

Reach 設定と部分修正

🎯 ゴール：修正したい部位だけ Reach を上げて局所的に直せる
  • 上半身はMocapのまま、足だけ修正するワークフローを試す
  • Head Effector を Reach 100% にして頭の向きを修正する
  • 特定フレームのみ Reach をキーフレームで変化させる（徐々にMocapに戻す）
  • Shoulder Effector で肩が不自然に上がるMocapを修正してみる
5〜6h
S6
MB

Floor Contact & 総合Mocap修正

🎯 ゴール：Floor Contact を設定し、Pinning と組み合わせた修正ができる
  • Character Properties で Foot Contact をオンにする
  • 床の高さ（Floor Y）を合わせる
  • ピン留めと Floor Contact を組み合わせて歩行クリップを仕上げる
  • 完成したアニメーションを Plot して確認
5〜6h
S7
MB

Story ウィンドウ & FBX 書き出し

🎯 ゴール：複数テイクをStoryでつなぎ、Maya向けFBXを書き出せる
  • Window → Story でStoryウィンドウを開く
  • 複数テイクをタイムラインに並べてつなぐ
  • つなぎ目にブレンド（Blend）を入れる
  • Story から Plot してFBXで書き出す
  • 書き出しFBXをMayaで開いて確認
5〜6h

📅 フェーズ 2 — MotionBuilder 応用（MB × 3）

MotionBuilder
応用操作・仕上げ力を上げる
フェーズ1を踏まえてより実践的な編集力をつける
S8
MB

上半身だけ差し替え（Upper Body Layering）

🎯 ゴール：下半身の歩行に別のクリップの上半身の腕振りを合成する
  • 2つのMocapテイクを用意する（歩行、腕を振る動作）
  • Story ウィンドウでトラックを分けてレイヤリングを試みる
  • または Character Controls で上半身だけ別キャラクターをInputに設定する方法を調べる
  • 完成形をベイクして確認
5〜6h
S9
MB

Auxiliary Effector（肘・膝の補正）

🎯 ゴール：補助エフェクターで関節の向きを修正できる
  • Knee Auxiliary Effector を選んで膝の向きを変えてみる
  • Elbow Auxiliary Effector で肘の飛び出し方向を修正
  • Mocapの「内股」「ガニ股」問題を実際に修正してみる
4〜5h
S10
MB

総復習 & 自由課題

🎯 ゴール：フェーズ1〜2で学んだ内容を使って1本のアニメーションを仕上げる
  • 自分で課題を設定してMocapデータを1本仕上げる
  • フットプラント・腰の高さ・頭の向きを組み合わせて修正
  • 仕上げてFBXで書き出し → Mayaで確認
  • 詰まった箇所をメモして次回以降の課題にする
5〜6h

📅 フェーズ 3 — Maya 入門（Maya × 4）

Maya
UI → アニメーション → FBXパイプライン
MBユーザーとして「Mayaでどこまでできるか」を把握する
S11
Maya

Maya UI & 基本操作

🎯 ゴール：Mayaを迷わず動かせる。Outliner・Channel Boxを使いこなせる
  • ビューポート操作（Alt+マウス）を確認
  • Q/W/E/R ツールで基本操作
  • Outliner でシーン階層を確認
  • Channel Box で数値入力
  • MBからFBXを読み込んでスケルトン構造を確認
4〜5h
S12
Maya

キーフレームアニメーション入門

🎯 ゴール：Sキーでキーを打ち、タイムラインを使ったポーズ to ポーズができる
  • シンプルなオブジェクト（Sphere等）でキーフレームを打つ練習
  • タイムラインでキーを移動・削除する
  • FBXで持ち込んだアニメーションのキーフレームを確認
  • 特定フレームのポーズを少し修正してキーを打ち直す
4〜6h
S13
Maya

Graph Editor でカーブを編集する

🎯 ゴール：Graph Editorでカーブを読み、タンジェントを調整してモーションを滑らかにできる
  • Graph Editorを開いてFBXのアニメーションカーブを表示する
  • キーをドラッグで移動・タンジェントを調整する
  • Flat / Spline / Stepped タンジェントの違いを試す
  • 不自然なカーブのスパイクを見つけて修正する
5〜6h
S14
MB+Maya

MBからMayaへの完全パイプライン実践

🎯 ゴール：MB修正 → FBX書き出し → Maya読み込み → Graph Editor微調整 → 確認 を1本通せる
  • MBでControl Rig修正 → Plot → FBX書き出し
  • MayaにFBX読み込み・スケール確認
  • Graph Editorで仕上げ微調整
  • カメラを付けてプレイブラスト（Playblast）でプレビュー動画を書き出す
5〜6h

セッション開始前に確認

今日のゴールを1行で書く。「〇〇ができるようになる」と決めてから起動するとトークンの無駄がない。

セッション終了前に確認

作業ファイルを保存。気づきや詰まった点をメモ。次回開始時に読み返すと時間の節約になる。

🪙

トークン節約のコツ

起動前に「今日何をするか」を決める。迷って時間を使うのが最大の無駄。チュートリアル動画はソフトを起動せず閲覧。

1セッション = 1ゴール
