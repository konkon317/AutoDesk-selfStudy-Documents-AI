② ポリゴンの構造とコンポーネント選択

メッシュは3種類の要素でできています。オブジェクトの上で右クリック長押しのマーキングメニューで、どの要素を選択・編集するかを切り替えます。これがモデリングの基本動作です。

Vertex（頂点）

位置を持つ点。UV や頂点カラーもここにぶら下がる（Unity の Mesh で見た「頂点属性」と同じもの）。

Edge（エッジ）

頂点をつなぐ線。ループ選択（ダブルクリック）で一周分をまとめて選べる。ベベルやシーム指定の単位。

Face（フェース）

エッジで囲まれた面。押し出し（Extrude）の対象。レンダリングされるのはこの面。

操作入力
コンポーネントモード切替オブジェクト上で右クリック長押し → Vertex / Edge / Face / Object Mode
エッジループ選択エッジをダブルクリック
ソフト選択のオン/オフB（周辺の頂点を減衰付きで一緒に動かす）
選択の追加 / 除外Shift+クリック / Ctrl+クリック
📌

Unity との視点の違い： Unity では Mesh は「完成品のアセット」で、頂点・UV は Mesh API 越しに読む対象でした。Maya ではその同じデータを手で直接編集します。「Unity で見ていたあの頂点配列を、今ビューポートで掴んでいる」と読み替えると早いです。

③ プリミティブから形を作る

Create → Polygon Primitives から Cube / Sphere / Cylinder / Plane などを作成します。ほとんどのモデリングは「一番近いプリミティブから彫り始める」が出発点です。

  • 作成直後に Channel Box 下段の INPUTS（polyCube1 など）を開くと、Subdivisions Width / Height / Depth を後から変更できる
  • これは Maya のコンストラクションヒストリー（作成手順を覚えている仕組み）によるもの。形が確定したら Edit → Delete by Type → History で履歴を確定・軽量化する
  • 単位・グリッドは MB→Maya パイプラインと同じ設定（Working Units）を使う
🖐

試してみる： Cube を作り、右クリック長押し → Vertex で頂点を1つ選んで W で動かす。次に B を押してソフト選択にして同じ頂点を動かし、周りがなだらかに付いてくる違いを確認。B の再押下で解除。

④ 主要編集ツール（Extrude / Bevel / Multi-Cut）

ツールは多数ありますが、まずこの表の範囲で「小物を1個作れる」状態を目指します。メニューはメニューセットを Modeling（F2）にして Edit Mesh / Mesh Tools から。

ツール場所 / ショートカット何をするか
Extrude（押し出し）Edit Mesh → Extrude / Ctrl+E選択フェース・エッジを複製して押し出す。形を「伸ばす・彫る」の主役
Bevel（面取り）Edit Mesh → Bevel / Ctrl+Bエッジに面取りを入れる。硬い角に微小な面を足すと光が乗って見栄えが上がる
Multi-CutMesh Tools → Multi-Cutエッジ・フェースを自由に切って分割線を足す。Ctrl+クリックでループ挿入
Insert Edge LoopMesh Tools → Insert Edge Loop一周分のエッジをまとめて挿入。分割の解像度を上げる定番
Merge（結合）Edit Mesh → Merge重なった頂点を1つに結合。パーツを繋いだ後の後始末に使う
🖐

試してみる（マグカップの入り口）： Cylinder を作成 → 右クリック長押し → Face で上面を選択 → Ctrl+E で Extrude し、表示されるマニピュレータの Offset を内側に少し縮める → もう一度 Ctrl+E して下方向に押し込む。これで「器」になります。Extrude を2回に分けるのがポイント（縮める→押し込む）。

⑤ UV 展開 — UV Editor の使い方

UV が「テクスチャを貼るための 2D 座標」であることは Unity の文脈で把握している前提で、ここでは Maya でどう切って、どう開くかだけを扱います。Unity で言えば、ここで作るものがそのまま Mesh.uv になります。

── UV 展開 ＝ 立体の展開図を作る作業 ──

開き方： Windows → Modeling Editors → UV Editor（横に UV Toolkit パネルが付いてきます。主要操作はほぼ UV Toolkit から実行します）

UV 展開の手順の型（この順で覚える）

投影でリセットする（Projection）

UV → Planar / Cylindrical / Automatic。乱れた UV をいったん素直な状態に投影し直す。「形に一番近い投影」を選ぶ（箱物なら Automatic、筒物なら Cylindrical）。

シームを切る（Cut / Sew）

展開の切れ目にしたいエッジを選び、UV Toolkit の Cut。切りすぎたら Sew で縫い戻す。目立たない場所（底・裏・服の脇線）に切れ目を置くのが定石。

Unfold で開く

UV シェルを選択して UV Toolkit の Unfold。シームで切った通りに、歪みが最小になるよう自動で平らに開いてくれる。

Layout で 0〜1 に敷き詰める

UV Toolkit の Layout。全シェルを重なりなく 0〜1 の UV 空間に配置する。テクスチャ解像度を稼ぎたいシェルは手動で大きめに置く。

チェッカーで歪みを確認する

UV Editor のチェッカーマップ表示をオンにして、ビューポート上で正方形が正方形に見えるかを確認。伸びて長方形に見える場所＝歪み。シームを足して Unfold し直す。

💡

シーム＝展開図のハサミの位置： UV 展開が上手くいかない原因はほぼ「切れ目が足りない or 位置が悪い」です。紙の箱をハサミで開くイメージで、「どこを切れば平らに置けるか」を先に考えると Unfold が素直に通ります。

📌

Unity への接続： ここで作った UV が FBX 経由で Unity の Mesh.uv（UV0）になります。ライトマップ用の UV2 は Unity のインポート設定「Generate Lightmap UVs」で自動生成させる手もあるので、手で作り込むのはまず UV0 だけで十分です。

⑥ マテリアルとテクスチャで UV を確認する

UV の出来はテクスチャを貼って初めて確認できます。ここではレンダリング品質ではなく「UV 確認のための最小限」だけ扱います。

  • オブジェクト上で右クリック長押し → Assign New Material → Lambert（または aiStandardSurface）を割り当てる
  • マテリアルの Color の右のチェッカーボタン → File を選び、画像テクスチャを読み込む
  • ビューポート上部の表示切替、またはショートカット 6（テクスチャ表示）/ 5（シェーディングのみ）で貼り付き具合を確認する
  • マテリアルの一覧・接続を眺めたくなったら Hypershade（Windows → Rendering Editors）——今の段階では「そういう物がある」でOK

⑦ よくある詰まりと対処

詰まり原因・対処
Extrude したら面が二重になった / 動かすと角が汚く割れるExtrude を実行した直後に何もせずもう一度実行している（ゼロ距離の押し出しが重なる）。Ctrl+Z で戻り、押し出しは「実行 → その場でマニピュレータを操作」を1セットで行う。
3 キーで滑らかにしたら形が崩れる三角形・五角形以上（ngon）が混ざっている。細分割は四角形主体だときれいに近似される。Multi-Cut で切り直して四角形に整える。
テクスチャを付けたのに表示されないビューポートがテクスチャ表示モードになっていない。6 キーを押す。
UV を開いたのにテクスチャが伸びる・歪むシーム不足のまま無理に開いている。歪んでいる場所の近くのエッジを Cut に追加して Unfold し直す。チェッカーの正方形が目安。
編集していると動作がどんどん重くなるコンストラクションヒストリーが溜まっている。形が確定した段階で Edit → Delete by Type → History を実行する。
