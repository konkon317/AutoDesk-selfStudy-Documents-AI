通し課題 — マグカップを Unity まで届ける

モデリング → UV → テクスチャ → FBX 書き出し → Unity 表示確認までを1個の成果物で通す作業指示書。読み物ではなく、Maya を起動した状態で横に置いて使います。

🪙 対応セッション：MY-S2〜S3（の実践パート）
📋 このページの前提
Maya 概要と基本操作 モデリング & UV（機能の理屈はこちら）

このページは「手順」だけに絞っています。なぜそうするかはモデリング & UV ページ、操作の詳しい手つきは各 STEP の参考リンク（GIF・動画）で補ってください。

🏁 完成条件（3つ揃ったらこの課題はクリア）

  • 形状：持ち手つきのマグカップが、Smooth プレビュー（3 キー）で破綻しない
  • UV：チェッカーマップの正方形が全面でほぼ正方形に見える
  • 受け渡し：Unity のシーンにテクスチャ付きで表示される

0

準備 — プロジェクトと単位

目安 15分
  1. File → Project Window で課題用プロジェクトを新規作成（例：mug_project）
  2. Windows → Settings/Preferences → Preferences → Settings で Working Units の Linear が cm（既定）であることを確認
  3. 空のシーンを mug_v01.mb として保存（以降 STEP ごとに v02, v03… と保存を分ける）
✔ 完了条件：プロジェクトフォルダが作られ、v01 が保存されている
🔗 参考：Start@Maya 7. プロジェクト設定とプリミティブオブジェクト
1

ベース形状 — Cylinder を器にする

目安 30分
  1. Create → Polygon Primitives → Cylinder を作成。Channel Box の INPUTS（polyCylinder1）で Subdivisions Axis = 16 程度に
  2. 右クリック長押し → Face で上面フェースを選択
  3. Ctrl+E（Extrude）→ マニピュレータの Offset で内側に縮める（縁の厚み分を残す）
  4. もう一度 Ctrl+E → 下方向に押し込んで器の内側を作る（底の厚みを残して止める）
📷 fig: 2段 Extrude 後の断面（実機セッションで撮影）
✔ 完了条件：横から見て、縁と底に厚みのある「器」の断面になっている
🤔 詰まったら：Extrude 直後に面が二重になる → モデリング ⑦ よくある詰まり
2

持ち手 — Extrude と Bridge

目安 60分
  1. 側面の上寄りのフェースを1枚選び、Ctrl+E → 外側へ少し押し出す
  2. Extrude を数回繰り返し、フェースを回転（E）させながら弧を描いて下へ曲げていく
  3. 持ち手の先端フェースと、本体側の接続先フェースを削除する
  4. 両方の開口部の縁を選択し、Edit Mesh → Bridge で繋ぐ
📷 fig: 持ち手の Extrude 経過と Bridge 前後（実機セッションで撮影）
✔ 完了条件：持ち手が本体と一体で繋がっていて、穴・浮いた面がない
🔗 手つきの詳細（GIF）：MODELING HAPPY — コーヒーカップモデリング（16工程）。持ち手・Bridge の操作はこの記事の GIF を見ながら進めるのが確実です
3

面取りとスムーズ確認

目安 30分
  1. 縁（飲み口）のエッジをダブルクリックでループ選択 → Ctrl+B（Bevel）で面取り
  2. 3 キーで Smooth プレビュー。形の破綻（へこみ・つまみ跡）がないか一周確認
  3. 崩れる場所があれば 1 で戻し、Multi-Cut / Insert Edge Loop でエッジを足して四角形主体に整える
✔ 完了条件：3 キーの状態で全周見ても破綻がない
🤔 詰まったら：Smooth で崩れる → モデリング ⑦（ngon 混在が典型）
4

クリーンアップ — 履歴とトランスフォーム

目安 15分
  1. Edit → Delete by Type → History でコンストラクションヒストリーを確定
  2. Modify → Freeze Transformations で Translate/Rotate をゼロ基準に
  3. Outliner でオブジェクト名を mug_body など意味のある名前に変更
✔ 完了条件：Channel Box の INPUTS が空で、Translate/Rotate が 0・Scale が 1 になっている
5

UV 展開

目安 60分
  1. Windows → Modeling Editors → UV Editor を開く
  2. 本体を選択し、UV → Cylindrical 投影でリセット（持ち手は Automatic でも可）
  3. シームを切る：内側の底・持ち手の内側など目立たないエッジを選んで UV Toolkit の Cut
  4. UV シェルを選択して Unfold → Layout で 0〜1 に敷き詰める
📷 fig: シーム位置と Unfold 後の UV シェル（実機セッションで撮影）
✔ 完了条件：UV シェルが 0〜1 空間に重なりなく収まっている
🔗 参考：Start@Maya 13. UV展開の基本 ／ 14. UV展開に便利な機能 ／ MODELING HAPPY — UV展開で主に使う3機能。理屈は モデリング ⑤
6

チェッカー確認とテクスチャ

目安 30分
  1. UV Editor のチェッカーマップ表示をオンにして、ビューポートで歪みを確認
  2. 伸びている場所があれば Cut を足して Unfold し直す
  3. 右クリック長押し → Assign New Material → Lambert、Color に File テクスチャ（好きな画像でOK）を繋ぐ
  4. 6 キーで貼り付き具合を確認
✔ 完了条件：チェッカーの正方形が全面でほぼ正方形。テクスチャの流れ・切れ目が意図どおり
🤔 詰まったら：テクスチャが出ない（6キー）・歪む（シーム不足）→ モデリング ⑦
7

FBX 書き出し → Unity 表示確認

目安 30分
  1. マグカップを選択して File → Export Selection、ファイルタイプ FBX（オプションは既定でOK。テクスチャは Embed Media か、画像ファイルを一緒に渡す）
  2. Unity プロジェクトの Assets にドラッグ＆ドロップ
  3. モデルのインポート設定 → Materials で Extract Textures / Extract Materials（Embed した場合）
  4. シーンに配置してテクスチャ付きで表示されるか確認
📷 fig: Unity シーンでの表示結果（実機セッションで撮影）
✔ 完了条件：Unity のシーンでテクスチャ付きマグカップが表示されている＝この通し課題クリア
🤔 詰まったら：Unity で面が裏返って見える → Maya 側で Mesh Display → Reverse（法線の向き）。大きさがおかしい → STEP 0 の単位設定と FBX Export の Scale を確認
📌
