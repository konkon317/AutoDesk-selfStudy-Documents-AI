MotionBuilder の基本概念

MocapMotion Capture / モーションキャプチャ

実演者の動きをセンサーやカメラで記録したデータ。そのままでは「素材」であり、修正・編集を経て使える状態になる。

Characterizeキャラクタライズ

キャラクターのスケルトンを MB 標準の人体定義に対応付ける作業。「このボーンは腰、これは左腕」と教えることで、Retarget や Control Rig が使えるようになる。

→ MB 概要 ⑤ ワークフロー整理
Character Definitionキャラクター定義

Characterize の結果できる「どのボーンが体のどの部位か」の対応表。これがあるキャラクター同士はモーションを行き来させられる。

Retargetリターゲット

あるキャラクターのモーションを、体格の違う別のキャラクターに移し替えること。Characterize 済み同士なら MB が体格差を吸収してくれる。

→ MB 概要 ⑤ ワークフロー整理
T-poseTポーズ

直立して両腕を水平に広げた基準姿勢。Characterize はこの姿勢を基準に対応付けを行うため、崩れているとマッピングがずれる。

Takeテイク

1つのシーンファイルの中に複数持てるアニメーションの「録画トラック」。テイクを切り替えると同じキャラクターで別のモーションを扱える。

→ MB 概要 ④ テイクシステム
Story ウィンドウStory Window

複数のテイクやクリップを時間軸に並べて、つなぎ・ブレンド・組み替えを行う MB の編集画面。

→ MB 概要 ⑦ Story ウィンドウ
NLENon-Linear Editing / 非線形編集

クリップを時間軸上に並べて自由に組み替える編集方式。Premiere など動画編集ソフトのタイムラインと同じ考え方で、Story ウィンドウはこれのアニメーション版。

HumanIKヒューマンアイケー

Autodesk 共通の人体 IK システム。MB の Characterize / Control Rig も Maya の HumanIK も同じ仕組みの上にあり、だからキャラクターデータを両ソフト間で行き来させられる。

Control Rig 関連

Control Rigコントロールリグ

スケルトンのボーンを直接触らずにアニメーションを編集するための操作用リグ。Mocap 修正もゼロからの手付けも、MB ではこれが共通の土台になる。

→ Control Rig ① なぜ必要か
FKForward Kinematics / フォワードキネマティクス

根元から順に各関節の角度を自分で指定して姿勢を作る方式。「肩を回し、肘を曲げ、手首をひねる」の順で決めていく。

→ Control Rig ② IK の理屈
IKInverse Kinematics / インバースキネマティクス

末端（手先・足先）の位置を指定し、途中の関節角度をソフトに逆算させる方式。「手をここに置きたい」から先に決められる。

→ Control Rig ② IK の理屈
FBIKFull-Body IK / フルボディIK

1本の腕・脚だけでなく全身のエフェクターが連動する MB の IK。手を引っ張ると必要に応じて体幹までついてくる。

ソルバーSolver

「末端をここに置く」などの条件を満たす関節角度を計算するプログラム。IK はソルバーが逆算してくれるから成り立つ。

エフェクターEffector

Control Rig 上でつかんで動かす操作点。手首・足首・腰など体の要所に配置され、これを動かすとソルバーが体を追従させる。

→ Control Rig ④ エフェクターの種類
Auxiliary Effector補助エフェクター

膝・肘などの「曲がる向き」を調整するための補助的なエフェクター。主要エフェクターだけでは決まらない中間関節の姿勢を制御する。

→ Control Rig ④ エフェクターの種類
ポールベクターPole Vector

IK で膝・肘がどの方向へ曲がるかを指示する矢印（ベクトル）。IK は末端位置だけでは関節の向きが一意に決まらないため、この指示が要る。

Reachリーチ

エフェクターが体を引っ張る強さ（0〜100%）。100% なら完全に IK に従い、0% なら元のモーションのまま。部分的な上書きの強度調整に使う。

→ Control Rig ⑤ Reach
IK Blend T / IK Blend Rアイケーブレンド

Reach の Properties パネル上での実際の名前。T が移動（Translation）、R が回転（Rotation）の上書き強度に対応する。

→ Control Rig ⑤ Reach
IK Pullアイケープル

エフェクターが「体全体」をどれだけ引っ張るかの設定。Reach（そのエフェクター自身の追従度）とは別の概念なので注意。

→ Control Rig ⑤ Reach
Pinningピン留め

エフェクターを空間に固定する機能。足を床にピン留めすれば、体を動かしても足が滑らない。

→ Control Rig ⑥ Pinning
Floor Contactフロアコンタクト

足や手が床にめり込まないよう自動で押し戻す機能。1フレームずつ直す代わりに、床面との接触をルールとして与える。

→ Control Rig ⑦ Floor Contact

アニメーション編集

キーフレームKeyframe

「このフレームでこの値」という記録点。キーとキーの間はソフトが補間で埋めるので、全フレームに値を打つ必要はない。

→ Maya アニメ ② キーフレーム
FCurveFunction Curve / ファンクションカーブ

値（位置・回転など）の時間変化を表す曲線。MB のカーブ編集画面の名前でもある。カーブの形＝動きの質。

→ アニメ基本 ③ FCurve エディタ
Graph Editorグラフエディタ

Maya のカーブ編集画面。役割は MB の FCurve エディタと同じで、名前と操作系が違う。

→ Maya アニメ ③ Graph Editor
タンジェントTangent

キーの前後でカーブがどんな傾きで出入りするかの設定。滑らか（Spline）・停止（Flat）・カクカク（Stepped）などで動きの性格が変わる。

→ Maya アニメ ③ Graph Editor
Dope Sheetドープシート

キーの「タイミングだけ」を一覧して移動できる編集画面。値の形はカーブエディタ、間の詰め方は Dope Sheet と使い分ける。

Pose to Poseポーズ・トゥ・ポーズ

主要なポーズ（キーポーズ）を先に全部置いてから、間のタイミングを後から詰めていく組み立て方。行き当たりばったりに頭から作るより破綻しにくい。

→ アニメ基本 ④ Pose to Pose
Animation Layerアニメーションレイヤー

元のアニメーションカーブを壊さず、差分だけを上のレイヤーに重ねて修正する仕組み。失敗してもレイヤーごと消せば元通り。

→ アニメ実践 ① Animation Layer
Plotプロット（ベイク / Bake）

リグやレイヤーの計算結果を、各フレームのキーとしてスケルトンやリグに焼き付けること。焼いた後は計算元がなくても同じ動きが再生できる。

→ アニメ実践 ② Plot
Butterworth フィルターバターワースフィルター

カーブの細かい振動（高周波成分）を落として滑らかにするフィルター。Mocap のノイズ取りや、修正でできた急な段差をならすのに使う。

Playblastプレイブラスト

Maya のビューポート表示をそのまま動画として書き出すプレビュー機能。レンダリングを待たずに動きの確認ができる。

パイプライン・ファイル形式

パイプラインPipeline

制作工程の連なり（収録 → 編集 → 仕上げ → 納品）と、その間でデータを受け渡す仕組みのこと。

→ 業界 ① MB の立ち位置
FBXエフビーエックス

Autodesk のシーン交換フォーマット。モデル・スケルトン・アニメーションをまとめて運べる。MB を使う限り最初に覚えるべき形式。

→ 業界 ③ 納品形態・ファイル形式
BVHビーブイエイチ

スケルトンとモーションだけを持つ古くからある Mocap 用フォーマット。キャプチャ機材からの出力によく使われる。

→ 業界 ③ 納品形態・ファイル形式
C3Dシースリーディー

光学式 Mocap の生データ形式。ボーンではなくマーカー（体に貼った点）の位置座標が入っている。

Alembicアレンビック（.abc）

頂点の動きを毎フレーム焼き込んで運ぶフォーマット。リグを持ち出せない/持ち出さない映像系の受け渡しで使われる。

→ 業界 ③ 納品形態・ファイル形式
USDUniversal Scene Description

Pixar 発のシーン記述フォーマット。大規模制作でシーン全体を工程間で共有するための業界標準になりつつある。

→ 業界 ③ 納品形態・ファイル形式
glTFジーエルティーエフ

Web・リアルタイム表示向けの軽量 3D フォーマット。ブラウザやアプリでの表示用途で使われる。

→ 業界 ③ 納品形態・ファイル形式
Quaternionクォータニオン

回転を4つの数値で表す方式。角度3つ（オイラー角）より補間が安定する。FBX 読み込み時の「回転の補間をどう扱うか」の設定に登場する。

→ Maya アニメ ④ FBX パイプライン

Maya

Outlinerアウトライナー

シーン内の全オブジェクトを階層ツリーで一覧する Maya のパネル。MB の Scene ブラウザに近い役割。

→ Maya 概要 ⑥ Outliner & Channel Box
Channel Boxチャンネルボックス

選択中オブジェクトの移動・回転・スケールなどの数値を直接見て打ち込める Maya のパネル。キーを打つ対象（チャンネル）の選択もここで行う。

→ Maya 概要 ⑥ Outliner & Channel Box
Dependency Graphディペンデンシーグラフ

Maya の内部がノード（計算単位）のつながりでできているという仕組みの名前。アニメーション操作を覚える段階では「そういう土台がある」程度の理解でよい。

トポロジーTopology

頂点・エッジ・フェースのつながり方（面の流れ）のこと。四角形主体のトポロジーだと細分割や変形がきれいに通り、三角形・多角形が混ざると崩れやすい。

→ モデリング ② ポリゴンの構造
コンストラクションヒストリーConstruction History

Maya が操作の手順を覚えている仕組み。Channel Box の INPUTS から作成後でも分割数などを変えられる反面、溜まると動作が重くなる（Delete History で確定）。

→ モデリング ③ プリミティブ
UVユーブイ

テクスチャを貼るための 2D 座標。3D 表面の各頂点が「テクスチャ画像のどこを参照するか」を持つ。Unity の Mesh.uv で見ていたものと同じデータ。

→ モデリング ⑤ UV 展開
シームSeam

UV 展開の切れ目。立体をどこで切って平らに開くかを決める、展開図のハサミの位置。歪みの大半はシーム不足が原因。

→ モデリング ⑤ UV 展開
