リギング課題 — 箱人形に骨を入れて動かす

超簡易な人型モデルを自作し、スケルトンを入れて、ポーズを付けて動かすまでの作業指示書。作り込みはしません——「メッシュが骨で動く」の仕組みを最短で一周して、リトポやエッジループの意味を先に体感するのが目的です。

🪙 対応セッション：MY-S7〜S8（MY-S3 完了後ならいつでも。アニメーションフェーズ MY-S4〜S6 と並行可）
📋 このページの前提
モデリング & UV（②〜④の基本ツール） 発展ロードマップ ③ リギングの中身（読み物）

UV・テクスチャはこの課題では使いません。操作の手つきは各 STEP の Start@Maya リギング編（16〜21）を横に置いて進めてください。

🏁 完成条件（3つ揃ったらこの課題はクリア）

  • モデル：頭・胴・腕・脚のある箱人形が1体ある（作り込みなし・左右対称）
  • リグ：ジョイントで肘・膝・肩・股関節が曲がり、メッシュが追従する
  • 動き：ポーズを付けてキーを打ち、短いアニメーション（手を振る等）が再生できる

STEP 一覧

  1. 準備 — プロジェクトとメニューセット
  2. 箱人形モデリング — 関節に分割を入れておく
  3. スケルトン作成 — ジョイントを中に組む
  4. バインド & ウェイト最小調整
  5. ポーズ → キー → 再生（潰れを観察する）
  6. 発展（任意）— HumanIK で MB に持ち込む
0

準備 — プロジェクトとメニューセット

目安 10分
  1. File → Project Window で課題用プロジェクトを作成（例：boxman_project）
  2. メニューセットを Rigging（F3）に切り替えられることを確認（モデリング中は F2 と行き来する）
  3. boxman_v01.mb として保存
✔ 完了条件：プロジェクトが作られ、F2 / F3 のメニュー切り替えを確認した
1

箱人形モデリング — 関節に分割を入れておく

目安 1〜2h
  1. Cube で胴体を作り、上面・側面・底面のフェースから Ctrl+E（Extrude）で頭・腕・脚を伸ばす（プリミティブを並べて組み合わせてもよい——1メッシュの方が後のバインドが素直）
  2. 肘・膝・肩・股関節に当たる位置に、Insert Edge Loop で分割を1〜2本入れる——ここが本課題の核。分割のない場所は曲がれない
  3. 片側だけ作って Mesh → Mirror で左右対称にしてもよい
  4. 形が決まったら Edit → Delete by Type → History と Modify → Freeze Transformations（バインド前の掃除。忘れると後で困る）
📷 fig: 箱人形と関節位置のエッジループ（実機セッションで撮影）
✔ 完了条件：箱人形が1体。関節位置に分割が入っていて、ヒストリーが空・トランスフォームがゼロ
🤔 作り込みたくなったら：この課題では禁止よりの非推奨。顔も指も要らない——目的は「動く仕組み」の理解で、造形は発展ロードマップの領域
2

スケルトン作成 — ジョイントを中に組む

目安 1h
  1. メニューセット Rigging（F3）→ Skeleton → Create Joints
  2. サイドビュー（Space で4分割 → Side）で腰 → 背骨 → 首 → 頭 の順にクリックして背骨の連鎖を作る
  3. 腰から脚（股関節 → 膝 → 足首）、胸から腕（肩 → 肘 → 手首）をそれぞれ作り、Outliner で親子階層を確認する
  4. ジョイントに名前を付ける（hips / spine / l_shoulder …）。左側を作って Skeleton → Mirror Joints で右側を生成
  5. ジョイントの位置がメッシュの関節（STEP 1 で分割を入れた場所）の内側に来ているかをビューで確認する
✔ 完了条件：Outliner で hips をルートとする1本の階層になっていて、全関節位置にジョイントがある
🔗 手つき：Start@Maya 16. スケルトン作成（補助ジョイントの 17 はこの課題ではスキップでOK）
3

バインド & ウェイト最小調整

目安 1〜2h
  1. メッシュとルートジョイント（hips）を選択 → Skin → Bind Skin（設定は既定でOK）
  2. 肩や膝のジョイントを E で回してみて、メッシュが追従することを確認 → 確認したら Ctrl+Z で戻す
  3. 曲げたときの食い込み・引っ張られが目立つ場所だけ、Skin → Paint Skin Weights で塗り直す（白＝そのジョイントに強く追従。ウェイトは合計1に自動正規化される）
  4. 全部を綺麗にしようとしない——「肩を曲げても腰が動かない」程度で合格
📷 fig: バインド直後の食い込みとウェイトペイント画面（実機セッションで撮影）
✔ 完了条件：肘・膝・肩・股関節を曲げてもメッシュが破綻せず付いてくる
🤔 詰まったら：バインド後に動かすと全体がズレる → STEP 1 の Freeze / Delete History を飛ばしている。Skin → Unbind Skin して掃除からやり直す。🔗 手つき：Start@Maya 18. スキニング
4

ポーズ → キー → 再生（潰れを観察する）

目安 1h
  1. フレーム1で全ジョイントを選択して S（初期ポーズのキー）
  2. フレーム15で腕のジョイントを回して「手を挙げる」ポーズ → S、フレーム30で戻して S
  3. 再生して、箱人形が手を振ることを確認する
  4. 観察：腕を大きく上げたとき、脇のメッシュがどう潰れる・伸びるかをよく見る
📷 fig: 手を挙げたポーズと脇の潰れ（実機セッションで撮影）
✔ 完了条件：短いアニメが再生できる＝この課題クリア
💡

ここで見た「脇の潰れ」が、リトポロジーの存在理由： 分割が足りない・エッジの流れが関節に沿っていないメッシュは、どうウェイトを塗っても綺麗に曲がりません。発展ロードマップのリトポ工程で「変形に耐えるエッジループ」を整えるのは、今日この箱人形で見た潰れを防ぐためです。

5

発展（任意）— HumanIK で MB に持ち込む

目安 1〜2h ⚠️ MB も使うため2トークン日
  1. Maya で Skeleton → HumanIK を開き、自作スケルトンをキャラクタライズする（各ジョイントを HumanIK の定義にマッピング。MB の Characterize と同じ作業）
  2. FBX で書き出して MB で開く
  3. 手持ちの Mocap データをリターゲットして、自作の箱人形が Mocap で歩き出すのを確認する
✔ 完了条件（任意）：自作モデルが既習の MB パイプラインに乗って動いた——ロードマップの出口を先取りで体験
🔗 手つき：Start@Maya 21. HumanIK ／ 既習：MB 概要（Characterize・Retarget）
