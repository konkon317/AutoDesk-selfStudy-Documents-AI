② Maya の位置づけ

MotionBuilderとの違い

  • モデリング・シェーダー・レンダリングまで一通りできる
  • リギングシステムが柔軟（カスタムリグを作れる）
  • ノードベースのDependency Graph が基盤（操作を覚える段階では「そういう土台がある」程度でOK）
  • MEL/Pythonで自動化できる
  • Mocap処理はMBほど直感的でない

MBとの役割分担（よくある例）

  • Mocap収録・クリーンアップ → MotionBuilder
  • リターゲット・Control Rig編集 → MotionBuilder
  • シーン組み・カメラワーク → Maya
  • キャラクター最終調整・表情 → Maya
  • レンダリング → Maya（Arnold等）

⑥ Outliner & Channel Box

Outliner

  • シーン内の全オブジェクトの一覧
  • 親子関係がツリーで見える
  • FBX読み込み後にスケルトン構造を確認するのに使う
  • Show → Joints などでフィルタリング可能
  • Ctrl+クリックで複数選択

Channel Box

  • 選択オブジェクトの Translate / Rotate / Scale が見える
  • 数値を直接入力できる
  • キーがついているチャンネルは赤く表示される
  • チャンネル名を右クリック → "Key Selected" で個別にキーを打てる

⑦ キーフレームアニメーション

MBのPlotとは異なり、Mayaではアニメーターが自分でキーフレームを打ってアニメーションを作ります。FBXで持ち込んだアニメーションはすでにキーフレームとして入っています。

🖐

試してみる： 新規シーンで Sphere を作り（Space→ Create → Sphere）、フレーム1で S、フレーム30でSphereをY方向に移動してもう一度 S。再生してポンと上がる動きを確認。これがキーフレームの最小単位。

⑧ Graph Editor（タンジェント種類の図解）

アニメーションカーブを視覚的に編集するウィンドウです。Mayaのアニメーション編集の中心。

開き方： Window → Animation Editors → Graph Editor

── Graph Editor の構成 ──

タンジェントの種類（図解）

タンジェントはキーフレーム間の補間方法を決めます。動きのなめらかさや緩急を制御する重要な設定です。

Spline（スプライン）

なめらかな曲線。イーズイン・イーズアウトが自動的につく。最も自然に見える動きになる。

Flat（フラット）

キーの出入りが水平になる。「止まってから動く」「ピタッと止まる」表現に使う。

Stepped（ステップ）

補間なしで値が瞬時に変わる。コマ撮りアニメ風や、アニマティクス（ラフ動画）の確認によく使う。

Graph Editor 基本操作

操作入力（Graph Editor内）
キーを選択クリック / ドラッグ選択
キーを移動（時間・値）選択して W → ドラッグ
タンジェントをFlat（水平）にShift+F
タンジェントをSplineにShift+T
全カーブをフィット表示A
選択カーブをフィット表示F

Maya でのFBX読み込み手順

  • File → Import（新規シーンに持ち込む）
  • ファイルタイプ "FBX" を選択
  • Import Options で "Animation" にチェックが入っているか確認
  • 読み込み後、Outlinerでスケルトン構造が展開されているか確認

よくある問題と対処

問題原因・対処
スケールが大きすぎる / 小さすぎるFBXエクスポート時の単位設定がズレている。MBのFBX Export設定でScaleを確認。
アニメーションが来ないPlot to Skeleton が完了しているか確認。Control Rigのままだとアニメーションが入っていないことがある。
ボーンが多すぎるMBでControl Rigを削除してから書き出す。
FBXオプションが出ないWindow → Settings/Preferences → Plug-in Manager で fbxmaya.mll をLoad & Auto Loadにチェック。
アニメーションにジッターが出るImport時に "Retain Quaternion Interpolation" を選択（"Resample as Euler" は使わない）。Quaternion は回転を4成分で表す方式で、オイラー角より補間が安定するため。
📌

fps の一致： MBのfpsとMayaのfpsが合っていないとアニメーションのタイミングがずれます。MayaのfpsはWindow → Settings/Preferences → Preferences → Settings → Working Units の "Time" で確認・設定してください。
