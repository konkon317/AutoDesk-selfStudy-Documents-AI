① FK / IK の選び方 — どちらで作るか

IK と FK の仕組み・切り替え方は Control Rig ② で学びました。ここでは「実際に作るとき、どの部位をどちらで扱うか」という判断基準の話です。

FK が向く場面

  • 体をひねる・上半身の表現——脊椎・腰のねじれはFK的な積み上げが自然
  • 流れるような腕振り——波打つような動きはFKの方がコントロールしやすい
  • 顔・首の向き——頭のコントロールはFK的な操作が直感的
  • 表情的な上半身——感情を乗せる動きはFKで細かく調整

IK が向く場面

  • 足を床に固定する——フットプラントは IK + Pinning が必須
  • 手で何かを掴む・触れる——物体の位置に手を合わせるのはIKが直感的
  • 重心移動を主体に考える——Hips Effector で全身の重心を動かす
  • 壁・机への接触——接触位置を固定したままキャラを動かす
💡

実際の制作では混在： 下半身はIK（足を地面に固定）、上半身はFK（腕の振りを細かく制御）という使い分けが一般的です。MBのControl Rigではエフェクターごとに独立してIK/FKを切り替えられます。

② 手付けの基本サイクル — キーを打つ

MB はMocap処理ソフトですが、Control Rig を使って手付けアニメーションをゼロから作ることもできます。基本サイクルは「フレームを決める → エフェクターを動かす → キーを打つ」の繰り返しです。

→
機能

理屈

基本キーイングサイクル（IK 手付け）

1

Control Rig を Active にして Reach を 100% に設定

全エフェクターの Reach（T・R 両方）を 100% にする。Mocap データがなければ 0% でも同じ結果になるが、意図を明確にするため 100% 推奨。

2

始点フレームへ移動してすべての Control をキー打ち

Transport Controls でフレームを指定。A で全オブジェクト選択 → K（または Character メニュー → Key All）でTポーズを初期キーとして記録する。

3

目的のフレームへ移動 → エフェクターを動かす

動かしたいエフェクターを選択して W（Move）または E（Rotate）で位置・角度を変更する。

4

K キーで選択中のエフェクターにキーを打つ

選択オブジェクトにキーが記録される。全身まとめて打ちたいときは A で全選択してから K。

5

次のキーフレームへ移動して繰り返す

主要ポーズだけ打ってから FCurve エディタでタイミングと緩急を調整する。ポーズ to ポーズの繰り返しがゼロ制作の基本単位。

📌

MBの手付けは「粗打ち → Mayaで仕上げ」が現実的： MB の Dope Sheet はキー管理が Maya より不便です。主要ポーズだけ MB で作り、FBX で Maya に渡してから Graph Editor で緩急・タイミングを整えるフローが実務では一般的です。

🚩 ここで一区切り — 最初のキーが打てたら
  • Reach 100% が何を意味するか、自分の言葉で言える
  • 好きなフレームにポーズを作り、K でキーを打てた
  • 再生して、キーとキーの間を MB が補間していることを確認した

③ FCurve エディタ — 動きの質を磨く

キーが打てるようになったら、次はキーとキーの間の話です。動きの「速い・遅い・タメ・キレ」は全部カーブの形で決まります。

MotionBuilderのFCurveエディタはMayaのGraph Editorと同じ役割を持ちます。両方使う場合、どちらかを覚えればもう一方は操作感がほぼ移植できます。

FBX経由で持ってきたアニメーションの確認： MBでMocapデータを開いた直後にFCurveエディタでカーブを見ると、ノイズや異常値（スパイク）が見えることがあります。修正前に一度確認しておくとどこを直すべきかが把握できます。

④ Pose to Pose — アニメーションを組み立てる

ポーズを作れるようになった次のステップ。Pose to Pose は「全フレームを順に打つ」のではなく、重要なポーズだけ先に決めて中割りは MB に補間させる方法です。実務・教育を問わず最も一般的な手付けアニメーションの作り方です。

やりたいこと
→
操作
→
理屈
動きの「山」になるポーズを決める
→
重要フレームにポーズを作って K
→
これが「原画」。キー間はMBがスプライン補間で埋める
動きの緩急・タイミングを整える
→
FCurve エディタでタンジェントを調整、または Dope Sheet でキーを移動
→
カーブの傾きが速度。Dope Sheet はキー位置を時間軸上で並べて視覚管理
ループアニメーションを作る
→
最初と最後のフレームに同じポーズをキーとして打つ
→
開始ポーズ = 終了ポーズにすることでシームレスにループする

Pose to Pose の基本ステップ

1

タイムラインのフレームレンジを設定する

画面下部のタイムラインで開始・終了フレームを指定する。短いループなら 0〜30（1秒）などで始めると管理しやすい。

2

フレーム 0 に基本ポーズを作って K

待機・初期状態のポーズを作り、全エフェクター選択（A）してから K でキーを打つ。

3

次の重要フレームに移動 → ポーズを変えて K

「動きの頂点」になるフレームに移動してポーズを作る。Kキーでキーを打つ。これを繰り返す。

4

再生して全体の流れを確認する

Space で再生。MB がキー間を補間した動きを確認する。ここで「タイミングがずれている」「動きが早すぎる」などを把握する。

5

FCurve エディタ / Dope Sheet でタイミングと緩急を調整

FCurve：カーブの傾き（速度）をタンジェント操作で整える。Dope Sheet：キー全体を俯瞰してフレーム単位で移動・コピーできる。

Dope Sheet と FCurve エディタは目的で使い分ける
Dope Sheet はキー位置（タイミング）を全ボーン横断で見るのに向いている。FCurve エディタは特定チャンネルの速度カーブを細かく操るのに向いている。「全体のリズムを整える → Dope Sheet、特定部位の緩急を詰める → FCurve」の順が実務では多い。

⑤ ゼロ制作ワークフロー — 通しでやってみる

①〜④のスキルを1本に繋げます。Mocap修正との違いが出るステップを強調しています。

1

キャラクターをCharacterize（Mocap修正と同じ）

CGモデルのスケルトンをMBに認識させる。ゼロ制作でも必要。

Mocap修正と同じ
2

Control Rigを作成（Mocap修正と同じ）

Character Controls → IK/FK Control Rig を作成。

Mocap修正と同じ
3

全エフェクターのReachを100%に設定

Mocap修正では「修正する部位だけ上げる」が、ゼロ制作では全部位を自分でコントロールするため全て100%にする。

ゼロ制作特有
4

フレーム0でT字ポーズ（またはAポーズ）を確認

キャラクターが正しい初期姿勢にあることを確認してからアニメーションを開始する。

ゼロ制作特有
5

主要ポーズをキーで打つ（Pose to Pose）

まず動きの「山」となるポーズだけキーを打つ。例: フレーム1（立ち）→ 30（ジャンプ頂点）→ 60（着地）。FCurveエディタで確認しながら進める。

ゼロ制作特有
6

中間ポーズ・タイミングを調整

FCurveエディタでカーブのタンジェントを整えて緩急をつける。必要に応じて中間フレームにキーを追加。

ゼロ制作特有
7

Plot to Skeleton → FBX書き出し（Mocap修正と同じ）

完成したらPlotしてスケルトンに焼き付け、FBXで書き出す。Plot の詳細（Control Rig への焼き戻しなど）は実践ワークフロー編で扱う。

Mocap修正と同じ
🏁 基本編クリアの目安
  • 短いループ（30〜60フレーム）を Pose to Pose で1本、通しで作れた
  • FCurve エディタでタンジェントを触り、動きの緩急が変わることを確認できた
  • Plot → FBX 書き出しまで自分の手で完了できた
